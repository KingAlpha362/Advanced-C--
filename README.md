# C++ Object-Oriented Practice

Short C++ exercises exploring polymorphism, classes, music lists, and recursion.

## ✨ Highlights

- Abstract base classes and overridden methods in `dogPolymorphism.cpp`.
- Student objects and a static counter in `linked-lists.cpp`.
- Additional practice in `musiclist.cpp` and `recursion-stokvel.cpp`.

## 🚀 Getting started

With a C++ compiler installed, compile one exercise at a time:

```sh
g++ -std=c++17 "dogPolymorphism.cpp" -o exercise
./exercise
```

On Windows PowerShell, use `-o exercise.exe` and run `.\exercise.exe`. Each exercise is separate; do not link every source file into one executable.
